# AttestHub - Attestation Evidence Collection Platform

A self-contained web application for managing payment scheme attestations (AusPayNet & AP+). Built for compliance teams to collect, review, and track attestation evidence across multiple crews.

## Features

- **Role-based access** — Admin, Reviewer, and Crew roles with scoped views
- **Attestation management** — Track multiple attestation types with custom checklists
- **Evidence collection** — Crews submit text responses and file uploads per checklist item
- **Review workflow** — Reviewers approve, reject, or request changes with comments
- **Progress tracking** — Dashboard showing completion status across all attestations
- **Admin panel** — Manage users and attestation assignments

## Quick Start

1. Open `AttestHub.html` in any modern browser (Chrome, Safari, Edge, Firefox)
2. Select a user from the login screen to explore different role views
3. No server, dependencies, or installation required

## Sample Attestations Included

- **AusPayNet Annual Security Attestation** — Network security, privileged access, incident response, encryption, vulnerability management
- **AP+ Fraud Control Attestation** — Fraud monitoring, anomaly detection, dispute resolution, staff training
- **AP+ Settlement Reconciliation** — Daily reconciliation, exception handling, regulatory reporting

## Tech Stack

- Vanilla HTML/CSS/JavaScript (no frameworks or dependencies)
- Single-file architecture for easy distribution

## Files

- `AttestHub.html` — Self-contained production app (open in browser)
- `attesthub.jsx` — React component version (for integration into React projects)
